# Binance Demo Telegram Trading Bot

> A Binance DEMO trading bot controlled from Telegram through webhooks.

![Python](https://img.shields.io/badge/Python-3.x-3776AB?logo=python&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green)


## Features

- Place demo orders on Binance from Telegram.
- Webhook based control flow.
- Simple command set.

## Tech Stack

| Layer | Technology |
|---|---|
| Exchange | Binance (demo) |
| Bot | Telegram bot API, webhooks |

## Quick Start

```bash
git clone https://github.com/dastonbek8747/binance-demo-telegram-trading-bot.git
cd binance-demo-telegram-trading-bot
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # add API keys and bot token
python main.py
```
